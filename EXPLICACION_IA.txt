26. speech_to_text 6.6.2 -> 7.4.0
    - speech_to_text: ^6.6.2 usaba jcenter() en su build.gradle (repositorio obsoleto)
    - Error: Could not find method jcenter() for arguments
    - Fix: actualizar a speech_to_text: ^7.4.0 en pubspec.yaml
    - API compatible (solo cambios internos: WASM, MacOS, build Android actualizado)
    - flutter pub get exitoso

27. INTERNET PERMISSION FALTANTE EN APK RELEASE
    - Debug (flutter run): Android agrega INTERNET automaticamente
    - Release (flutter build apk --release): NO lo agrega
    - Causa raiz del Error: ServerFailure en telefonos de companeros
      (ellos instalaban APK release sin internet, la app no podia contactar Supabase)
    - Fix: agregar <uses-permission android:name="android.permission.INTERNET"/>
      en android/app/src/main/AndroidManifest.xml
    - flutter clean + flutter pub get + flutter build apk --release
    - APK release generado: build/app/outputs/flutter-apk/app-release.apk (54.6MB)
